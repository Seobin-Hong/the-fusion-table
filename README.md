# The Shared Table

여러 식사 문화의 배치를 탐색하는 인터랙티브 테이블 프로토타입입니다. 게스트 수와 테이블 모양을 선택하면 좌석과 식기, 공유 음식 배치가 자동으로 바뀝니다.

## 실행 방법

1. Node.js 20 이상을 설치합니다.
2. 이 폴더에서 터미널을 엽니다.
3. 처음 한 번 `npm install`을 실행합니다.
4. `npm run dev`를 실행하고 Vite가 알려주는 주소(보통 `http://localhost:5173`)를 브라우저에서 엽니다.

배포 빌드는 `npm run build`로 만들 수 있습니다.

## 조작

- 문화 유형 옆 숫자를 직접 입력하거나 − / + 버튼으로 조정하면 테이블 배치가 자동으로 추천됩니다. 인원수는 유형별 0–16명 범위입니다.
- 하단의 원형·정사각형·직사각형 버튼을 누르면 해당 모양의 둘레에 맞춰 좌석과 배치가 다시 계산됩니다.
- 왼쪽 식기 아이콘은 현재 추천 배치에 포함된 종류를 밝게 표시합니다.
- Western, Japanese, Korean, Chinese Hotpot, South Indian, Ethiopian, Filipino, Jordanian과 프랑스식 2종, Spanish Tapas, Italian Family-style, Swedish Smörgåsbord, Georgian Supra, Basque Pintxos, British Afternoon Tea 배치를 참고할 수 있습니다.

태블릿 사용을 고려해 숫자 조절 버튼을 크게 만들었고, 문화 목록은 세로로 스크롤됩니다. 상단 언어 선택기에서 한국어, 영어, 일본어, 중국어, 프랑스어, 스페인어, 이탈리아어, 스웨덴어, 타밀어, 암하라어, 필리핀어, 아랍어, 조지아어, 바스크어로 전환할 수 있습니다. 국기와 식기 그림은 모두 흑백 그래픽입니다.

각 배치는 참고용 시각 예시입니다. 한 문화 안에서도 가정, 지역, 상황에 따라 식사 방식은 달라질 수 있습니다.
